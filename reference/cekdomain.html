FAQ

Questions, answered

What is CekDomain.ink?
CekDomain.ink is a modern domain availability checker. Type a domain, find out instantly if it's free or taken, and get brandable alternatives when it's already registered, all in one clean screen.
How does the domain checker work?
Your input is cleaned and validated, then sent to a server-side endpoint that checks availability. In production it plugs into a real WHOIS/domain API; in development it uses a deterministic mock so you can test the full flow without any keys.
Can I get suggestions with the same extension?
Always. If you search a .com and it's taken, every suggestion is also a .com. Search a .net and you get .net ideas. The TLD you chose is respected across all suggestions, and we surface the ones that look available first.
What happens after I click checkout?
You're redirected to the registration page with your chosen domain passed along as a query parameter, so it's ready to complete without retyping.
Does this guarantee domain ownership?
No. Availability can change second to second. A domain is only yours once registration is fully completed and confirmed by the registrar at checkout.
